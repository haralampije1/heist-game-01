Night Shift — a complete, original heist game built from static files: cross the room, take the loot, reach the exit before the alarm hits 100. Guards patrol with vision cones, cameras sweep beams, and you can throw distractions to pull them away. Played with keyboard and mouse; no network request, no build step.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
